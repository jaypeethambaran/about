# IT Budget Dashboard (prototype)

A local, offline dashboard for the coming year's corporate IT budget for **licences, services and contracts**. You give it a spreadsheet; it validates the data and produces a single static web page with headline figures, spend breakdowns, a renewal and notice-deadline timeline, monthly phasing, a prior-year bridge, a line-item explorer and a data-quality panel.

> **Status:** prototype built to hand over to another Claude Code installation, which will move it to the company GitLab. Read [`docs/HANDOVER.md`](docs/HANDOVER.md) first if that's you.

## Quick start

Requirements: **Python 3.9+** (standard library only, no `pip install`) and any modern browser.

```bash
python3 scripts/build_data.py data/sample-budget.xlsx
```

Then open `site/index.html` in a browser by double-clicking it. No web server is needed.

To use your own budget, fill in [`data/budget-template.xlsx`](data/budget-template.xlsx) (keep the sheet name `Budget`), then:

```bash
python3 scripts/build_data.py path/to/your-budget.xlsx --year 2027
```

- **Errors** (missing columns, duplicate IDs, bad dates, mixed currencies…) stop the build, and `site/data.js` is left unchanged.
- **Warnings** (no owner, renewal date passed, phasing doesn't add up…) are allowed and appear in the dashboard's *Data quality* section.
- Both are written to [`reports/validation-report.md`](reports/validation-report.md).

## What's in the dashboard

| Section | Shows |
|---|---|
| Headline figures | Total budget, change vs prior year, category split, notice deadlines in the next 90 days, % of budget with no owner |
| Where the money goes | Bars by cost pool, top 10 vendors (+ concentration), cost centre, OPEX/CAPEX, tower. **Click any bar to filter everything.** |
| Renewals & notice deadlines | Timeline of renewals (size = value, colour = urgency of the notice deadline), plus a table of what needs action within 90 days |
| Monthly phasing | Stacked monthly cash view by category; lines without monthly figures are spread evenly and the share is stated |
| Change from prior year | Waterfall: prior year → new lines → increases → decreases → removed → budget year |
| Line items | Sortable table of the filtered lines, with CSV export |
| Data quality | Coverage of owner, cost centre, prior-year and phasing data, plus every validation warning |

Filters (category, cost pool, tower, cost centre, vendor, owner, free-text search) apply to every section and are kept in the URL after `#`, so a filtered view can be bookmarked.

## Tests

```bash
python3 -m unittest discover -s tests -v
```

```bash
node tests/smoke_test.cjs
```

The browser test is optional and needs Playwright with Chromium. It opens the page from disk and checks that totals reconcile, filters work, the layout has no horizontal scroll at phone width, and there are no console errors.

## Privacy

Real budget and contract data is commercially sensitive. Keep real spreadsheets **out of git** unless the repository is private and access-controlled. The `.gitignore` here ignores `data/private/` for that purpose. The dashboard makes no network requests: no CDNs, fonts or analytics.
